# VantaTest sound library

This folder contains 30 original, synthesized interface sounds used by the VantaTest sound lab. They are intentionally small WAV files so supported Roblox executors can download, cache, and load them with `getcustomasset` or `getsynasset`.

The sounds are grouped into 12 selectable styles: Vanta Pulse, Glass, Soft, Mechanical, Digital, Cyber, Deep, Arcade, Crystal, Bubble, Minimal, and Retro. Every GUI event can also be assigned any individual sound through the public sound API or the interactive controls in `test.lua`.

These files are part of VantaTest and are covered by the repository license. No third-party audio was included.
